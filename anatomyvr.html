AnatomyVR — Demo

README
  1. This is the beta version of the 3D Study Aid for 20 Muscles Project.
  2. This does not support Mobile phone use.
  3. Fullscreen is now enabled. If you notice performance issues, switch back to the default window size.
  4. To rotate: WINDOWS: Rotate with right mouse click; MAC: track pad, double click and hold.
  5. The quizzes require exact and precise answers in use of capital letters and spelling. We are working towards having flexible rules regarding the exact match of the answers.
  6. If you get stuck with any quiz, after 3 wrong attempts, you will be able to see the correct answer and move on.
  7. Any clicks should stay in the answer box. It does not clear, backspace works.
  8. We appreciate your feedback to help improve this Project.

Not available on mobile

This Unity demo isn’t optimized for phones. Please switch to a laptop or desktop to view it.
