🎉 Navigation Dropdown System Demo

This page demonstrates the new responsive navigation system with different behaviors for desktop and mobile.

📋 Testing Instructions

🖥️ Desktop Testing (> 700px)

  • Hover over "Projects" or "Learning"
  • Dropdown menu should appear below
  • Menu disappears when you move mouse away
  • Use Tab key to navigate
  • Dropdowns open on keyboard focus too

📱 Mobile Testing (≤ 700px)

  • Click hamburger menu (☰) to open sidebar
  • Menu slides in from the left
  • Tap "+ button next to Projects/Learning
  • Submenu expands inline (accordion style)
  • Only one submenu can be open at a time
  • Tap any link to close the menu
  • Click outside to close the menu

✅ Key Features

  • Single HTML structure - No duplicated markup for mobile vs desktop
  • CSS-only desktop dropdowns - Hover-based, no JavaScript needed
  • Accordion mobile submenus - Only one submenu open at a time
  • Keyboard accessible - Full keyboard navigation support
  • ARIA attributes - Screen reader friendly
  • Smooth animations - Hardware-accelerated transitions
  • Dark mode support - Uses CSS variables
