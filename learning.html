Instructions for getting a GitHub Student Developer Pack

  1. Create a GitHub Account

    1. Click Profile → Settings.
    2. Go to Password and authentication → enable 2FA (Two-Factor Authentication).
    3. Install the Google Authenticator app on your phone (required for 2FA).
    4. (Click to expand images)

  2. Add Your Billing Address (No Credit Card)

    1. Click Profile → Settings.
    2. Go to Billing and licensing.
    3. Under the drop-down, click Payment history.
    4. Add your billing address. Do NOT add credit card info — only the billing address.

  3. Apply for Education Benefits

    1. Under Billing and licensing, find Education benefits.
    2. Click Education benefits → Start application.
    3. If needed, add your school email under Emails.

Running ROS 2 with Linux

ROS 2 (Robot Operating System 2) is used to build complex robot applications. It keeps your robot's parts in sync with one another. Since, ROS 2 needs the Linux operating system to run, you will likely need WSL (Windows Subsystem for Linux) to let Linux binaries run on your Windows-powered machine.
