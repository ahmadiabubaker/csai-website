AI Recipe Finder

Built by: Michael Rodriguez

Project Overview

AI Recipe Finder is an intelligent cooking companion that helps users discover recipes based on ingredients they have at home. Using computer vision and natural language processing, the app can identify ingredients from photos and suggest delicious recipes that match dietary preferences and cooking skill levels.

Key Features

  • Ingredient Recognition: Take photos of ingredients and the AI identifies them automatically
  • Smart Recipe Matching: Get recipe suggestions based on available ingredients
  • Dietary Filters: Support for vegan, vegetarian, gluten-free, and other dietary restrictions
  • Nutritional Information: Automated calculation of calories and macros for each recipe
  • Step-by-Step Guidance: Voice-activated cooking instructions

Technologies Used

  • Python with Django for backend
  • TensorFlow and OpenCV for image recognition
  • GPT API for recipe generation and adaptation
  • React Native for mobile app
  • MongoDB for recipe database

Learning Outcomes

Students learned computer vision techniques, working with image datasets, API integration, mobile app development, and creating recommendation systems. The project also covered user experience design for mobile applications and working with real-time data.

Future Enhancements

  • AR cooking instructions overlay
  • Meal planning and grocery list generation
  • Social features to share recipes with friends
  • Integration with smart kitchen appliances
