Smart Budget Tracker

Built by: Emily Wong

Project Overview

Smart Budget Tracker is a personal finance application that uses AI to help users manage their money more effectively. The app automatically categorizes expenses, predicts future spending patterns, and provides personalized recommendations for saving and budgeting.

Key Features

  • Automatic Categorization: AI categorizes transactions from bank statements and receipts
  • Spending Predictions: ML models forecast future expenses based on historical data
  • Smart Alerts: Get notified when you're approaching budget limits
  • Receipt Scanning: OCR technology extracts data from receipt photos
  • Financial Insights: AI-generated reports on spending habits and saving opportunities

Technologies Used

  • Vue.js for frontend interface
  • Python with FastAPI for backend
  • Scikit-learn for expense prediction models
  • Tesseract OCR for receipt scanning
  • PostgreSQL for financial data storage
  • Plaid API for bank integration

Learning Outcomes

This project taught students about financial data security, machine learning for time series prediction, OCR implementation, API integration with banking services, and building secure authentication systems. Students also learned about data visualization and creating actionable insights from financial data.

Future Enhancements

  • Investment tracking and portfolio analysis
  • Bill payment reminders and automation
  • Financial goal setting with AI coaching
  • Multi-currency support for international users
